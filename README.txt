PORTOFOLIO - PANDUAN SINGKAT

STRUKTUR FOLDER
  index.html                  halaman utama (isi teks: nama, deskripsi, proyek, dll)
  css/style.css               semua tampilan dan warna
  js/main.js                  semua interaksi dan animasi
  assets/backgrounds/         GAMBAR LATAR (ganti di sini)

CARA MENGGANTI GAMBAR LATAR
  Timpa file di assets/backgrounds/ dengan gambarmu. Nama file harus sama:
    home.jpg      landing page
    projects.jpg  halaman Projects
    skills.jpg    halaman Skills
    about.jpg     halaman About
    contact.jpg   halaman Contact
  Saran: JPG, ukuran 1920x1080 atau lebih, di bawah 500 KB supaya cepat dimuat.
  Kalau memakai PNG atau WEBP, ubah nama file di css/style.css (cari "GAMBAR LATAR").

MENGATUR TAMPILAN GAMBAR (css/style.css, bagian GAMBAR LATAR)
  --img-dim   tingkat gelap gambar (0 sampai 1). Naikkan jika teks sulit dibaca.
  --img-move  kekuatan gerak parallax mouse. Isi 0px untuk mematikan.

CARA MEMBUKA
  Klik dua kali index.html. Butuh internet untuk memuat font Google.
  Untuk dipasang online, unggah seluruh folder ini (misalnya ke GitHub Pages atau Netlify).

CATATAN
  Pastikan kamu punya izin memakai gambar yang dipasang.
